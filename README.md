* отображение всех договоров (актуальных/неактуальных/оплаченных/неоплаченных/выполненных/невыполненных/оплаченных/неоплаченных)

* добавление нового договора
* добавление этапов и отдельных работ в договор
* составления отчетов в docx документов со списком договоров
